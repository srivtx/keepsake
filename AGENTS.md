# AGENTS.md

## Project

keepsake is an open, encrypted format for personal AI memory (`keepsake/v1`) plus a reference implementation: a browser app, a Bun CLI, and an MCP server. A memory is a hashed **Cell**; a **Vault** is one JSON file holding the cells sealed with AES-256-GCM under a PBKDF2-SHA256 key, with a Merkle root committing to the plaintext. Transport is the file itself: there is no server, no account, no network call, and no telemetry. Output is human-readable text or stable JSON.

## Commands

- `bun install` — install dependencies.
- `bun test` — run the test suite in `tests/`.
- `bun run typecheck` — `tsc --noEmit`.
- `bun run build:site` — bundle `src/index.ts` into `site/assets/app.js` (esbuild, IIFE, global `Keepsake`).
- `bun run check:site` — validate every `site/*.html`.

## Layout

- `src/` — implementation. Must stay browser-safe (no `node:` imports); the same code runs in the browser app and the CLI.
- `src/cli.ts` — the `keepsake` CLI entry point.
- `src/mcp.ts` — the MCP server entry point.
- `src/import/` — import parsers that turn exports and notes into cells.
- `src/mcp/` — MCP server wiring.
- `tests/` — `bun test` files.
- `spec/` — the normative `SPEC.md`, `keepsake-v1.schema.json`, and `vectors.json`.
- `site/` — static pages and `site/assets/` (styles, self-hosted fonts, the generated browser bundle).
- `site/assets/vendor/transformers.min.js` — self-hosted Transformers.js v3 ESM bundle for the browser app's optional semantic recall.
- `site/models/Xenova/all-MiniLM-L6-v2/` — self-hosted `Xenova/all-MiniLM-L6-v2` model (`dtype: q8`), including `onnx/model_quantized.onnx`.
- `site/wasm/` — self-hosted ONNX Runtime Web WASM binaries (`ort-wasm-simd-threaded.jsep.wasm` and `.mjs`).
- `scripts/` — `build-site.mjs` and `check-site.mjs`.
- `action.yml` — composite GitHub Action that verifies a committed vault in CI (sets up Bun, runs `keepsake verify`).

## Conventions and hard rules

- `src/` must stay browser-safe: no `node:` imports and no Node-only globals, because it is bundled for the browser. Use WebCrypto (`crypto.subtle`), `TextEncoder`, and standard web APIs. Node-only code belongs in `src/cli.ts`.
- The site is fully static and offline: no external scripts or stylesheets, no network `src`, no telemetry.
- `site/assets/lens.css` is a shared design system copied byte-identical across the Lenses suite. Do not diverge it; per-tool changes go in `site/assets/theme.css`.
- `site/assets/app.js` is generated by `scripts/build-site.mjs`. Edit `src/`, then rebuild; never hand-edit the bundle.
- `site/assets/fonts/*.woff2` are self-hosted Geist (SIL Open Font License 1.1). Do not swap them for a CDN.
- The semantic-recall assets (`site/assets/vendor/transformers.min.js`, `site/models/Xenova/all-MiniLM-L6-v2/`, `site/wasm/`) are self-hosted so the site stays fully offline. Never replace them with a CDN or enable remote model loading, and keep `env.allowRemoteModels = false` in the app.
- Every `site/*.html` must pass `bun run check:site`: exactly one `<h1>` and one `<main>`, a skip link whose `#fragment` matches an element id, and only classes defined in `lens.css` or `theme.css`.
- The `keepsake/v1` format is stable. The Cell and Vault member sets, the canonical JSON rules, the Merkle rule, and the KDF/AEAD parameters do not change without a new format version.
- The CLI contract is stable: the commands `import`, `search`, `export`, `verify`, `stats`, `mcp`, `merge`, `forget`, `rotate`, `diff`, and `context`, and exit codes `0` (ok), `1` (findings or a negative result), `2` (usage or parse error), `3` (I/O error). The MCP server exposes `memory_recall`, `memory_remember`, `memory_stats`, `memory_verify`, `memory_context`, and `memory_forget`; adding a tool is additive and does not change the vault format.
